Connect your private vault

The interface is published, but no private storage has been connected. Documents must never be uploaded to a public GitHub repository.

1
Make a dedicated Supabase project for your household's travel wallet.
2
Run the included schema.sql in that project's SQL Editor. Create your family member accounts and approve their user IDs as shown in the SQL comments.
3
Set supabaseUrl and supabasePublishableKey in config.js (publishable key only, never the service-role key). Configure the site's URL as an auth redirect in Supabase.
Do not add passports, booking numbers, tickets, or any private files until login and database security are configured and tested.
